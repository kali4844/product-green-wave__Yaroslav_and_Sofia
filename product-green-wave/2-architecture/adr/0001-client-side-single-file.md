# ADR 0001. Клієнтський застосунок в одному HTML-файлі

- **Статус:** прийнято
- **Контекст:** розрахунок зеленої хвилі легкий, даних для збереження немає. Сайт потрібно розмістити на Google Sites і показати викладачу без встановлення. Команда складається з 2 осіб.
- **Варіанти:**
  1. Один HTML-файл із вбудованими CSS і JavaScript.
  2. Односторінковий застосунок на фреймворку (React, Vue) зі збіркою.
  3. Клієнт-серверний застосунок із бекендом.
- **Рішення:** варіант 1.
- **Наслідки:** плюси: розгортання одним файлом, робота офлайн, нуль зовнішніх залежностей, швидкий старт. Мінуси: файл зростатиме разом із функціями, складніше покривати модульними тестами (потрібна імітація DOM). Якщо файл перевищить ~100 КБ (NFR-04), його розділяють на ES-модулі.
