# ADR 0004. Розміщення: GitHub для документів, Google Sites для сайту

- **Статус:** прийнято
- **Контекст:** курс вимагає репозиторій GitHub із документами, а працюючий продукт має відкриватися за посиланням. У команди вже є домен, привʼязаний до Google Sites.
- **Варіанти:**
  1. Google Sites із вбудованим HTML-кодом застосунку.
  2. GitHub Pages із файлом `index.html`.
  3. Окремий хостинг (Firebase, Netlify).
- **Рішення:** документація й тег `v1.0.0` у GitHub, сайт у Google Sites (варіант 1). Файл у репозиторії лишається джерелом істини; GitHub Pages — запасний варіант, якщо вбудовування не працюватиме.
- **Наслідки:** сайт відкривається на домені команди без додаткових витрат. Мінус: застосунок показується у вбудованому блоці, що може бути тісним на телефоні (NFR-03 перевіряється окремо). Для відкату достатньо вставити код попередньої версії з тега.
