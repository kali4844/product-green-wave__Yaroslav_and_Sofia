# ADR 0002. Детермінована модель із постійною швидкістю

- **Статус:** прийнято
- **Контекст:** потрібно відповісти на запитання «з якою швидкістю проїхати без зупинок» і наочно показати це користувачеві й викладачу.
- **Варіанти:**
  1. Детермінований розрахунок для одного автомобіля з постійною швидкістю.
  2. Мікроскопічна імітація потоку (розгін, гальмування, черги), наприклад у спеціалізованих пакетах.
  3. Імовірнісна модель із випадковими прибуттями.
- **Рішення:** варіант 1, жовтий сигнал входить у червоний, старт після червоного миттєвий.
- **Наслідки:** результат відтворюваний, його можна перевірити вручну (тест-кейси TC-01…TC-12), графік простий для пояснення. Реальний потік складніший, тому значення слід розглядати як оцінку (ризик R-01 у [risks.md](../../5-management/risks.md)).
