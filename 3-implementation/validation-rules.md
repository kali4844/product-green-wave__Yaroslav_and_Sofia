# Правила валідації вхідних даних

Перевіряються всі поля форми MVP. Порожнє числове поле читається як 0 і потрапляє під ті самі правила. Повідомлення виводяться в інтерфейсі російською мовою, у такому вигляді, як наведено нижче. Реалізація: функція `validate()`, тести: TC-21…TC-31, TC-38.

| ID | Поле | Правило | Валідне значення | Невалідне значення | Повідомлення про помилку |
| --- | --- | --- | --- | --- | --- |
| VR-01 | Довжина маршруту | число від 1 до 50 000 м | 1600 | 0 | Длина маршрута: от 1 до 50 000 м |
| VR-02 | Скорость автомобиля | від 1 до 200 км/год | 200 | 0,9; 200,1 | Скорость автомобиля: от 1 до 200 км/ч |
| VR-03 | Мин. допустимая скорость | не менше 1 км/год | 20 | 0 | Минимальная скорость должна быть не меньше 1 км/ч |
| VR-04 | Макс. допустимая скорость | не менше мінімальної і не більше 200 км/год | 60 (при мін. 20) | 40 (при мін. 50); 201 | Максимальная скорость: не меньше минимальной и не больше 200 км/ч |
| VR-05 | Момент старта | не менше 0 с | 0 | -1 | Момент старта не может быть отрицательным |
| VR-06 | Запас до смены сигнала | від 0 до 30 с | 3 | 30,1 | Запас до смены сигнала: от 0 до 30 с |
| VR-07 | Длина колонны | від 0 до 120 с | 10 | 121 | Длина колонны: от 0 до 120 с |
| VR-08 | Список светофоров | не менше одного світлофора | 4 рядки | порожній список | Добавьте хотя бы один светофор |
| VR-09 | Светофор: расстояние | більше 0 м | 300 | 0; -50 | Светофор N: расстояние должно быть больше 0 |
| VR-10 | Светофор: зелёный | більше 0 с | 30 | 0 | Светофор N: зелёный должен быть больше 0 |
| VR-11 | Светофор: красный | не менше 0 с | 30; 0 | -5 | Светофор N: красный не может быть отрицательным |
| VR-12 | Светофор: сдвиг фазы | довільне число (враховується за модулем циклу) | 10; -10 | — | немає (обмежень немає) |

Відомі прогалини: дві світлофори з однаковою відстанню не відхиляються (RV-11 у [review-report.md](../4-quality/review-report.md)), нечислове введення блокується типом поля `number` браузера.
