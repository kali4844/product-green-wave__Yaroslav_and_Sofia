# Контракт API ядра розрахунку

Компонент: **ядро розрахунку** (модулі M2, M3, M4). Версія контракту: **1.0**. Операції — функції сторінки; параметри форми й масив світлофорів передаються як контекст (читаються зі стану сторінки).

## Операції

| Операція | Параметри | Відповідь | Помилки |
| --- | --- | --- | --- |
| `simulate(speedKmh)` | `speedKmh` — число, км/год | обʼєкт `Result` | при `speedKmh < 0,1` значення замінюється на 0,1 |
| `scanSpeeds()` | контекст: `speedMinKmh`, `speedMaxKmh`, `marginS` | обʼєкт `Scan` | немає, дані мають бути попередньо перевірені `validate()` |
| `groupRanges(speeds)` | `speeds` — масив чисел | масив інтервалів `[від, до]` | порожній масив → порожній результат |
| `recommendTiming(light, speedKmh)` | `light` — обʼєкт світлофора; `speedKmh` | обʼєкт `Recommendation` | немає |
| `applyTiming(speedKmh)` | `speedKmh` | змінює `green`, `red`, `offset` у всіх світлофорах | якщо `validate()` повертає помилки, зміни не застосовуються |
| `validate()` | немає | масив рядків-помилок (порожній = дані коректні) | немає |

## Типи відповідей

```text
Result = { total, avg, stops, waitSum, minMg, rows[], pts[] }
  total   — час у дорозі, с;  avg — середня швидкість, км/год
  stops   — кількість зупинок;  waitSum — сумарне очікування, с
  minMg   — мінімальний запас до зміни сигналу, с
  rows[i] = { arr, green, wait, mg }
Scan = { ok[], best, opt, reserve }
  ok[] — швидкості без зупинок;  opt = { v, r } — оптимальна швидкість і її Result
  reserve — true, якщо запас не менший за заданий
Recommendation = { arr, g, r, o }  (час прибуття, зелений, червоний, зсув; с)
```

## Приклади

### simulate

Контекст: маршрут 1000 м, момент старту 0, один світлофор `{d: 500, g: 30, r: 30, o: 0}`.

Запит: `simulate(36)`

```json
{ "total": 110, "avg": 32.7, "stops": 1, "waitSum": 10, "minMg": 0,
  "rows": [ { "arr": 50, "green": false, "wait": 10, "mg": 0 } ] }
```

Запит: `simulate(72)`

```json
{ "total": 50, "avg": 72, "stops": 0, "waitSum": 0, "minMg": 5,
  "rows": [ { "arr": 25, "green": true, "wait": 0, "mg": 5 } ] }
```

### scanSpeeds

Контекст: той самий світлофор, діапазон 20-55 км/год, запас 3 с.

```json
{ "opt": { "v": 28.5 }, "reserve": true }
```

### groupRanges

Запит: `groupRanges([30, 29.9, 29.8, 20.3, 20.2])`

```json
[ [20.2, 20.3], [29.8, 30] ]
```

### recommendTiming

Контекст: запас 3 с, колона 10 с. Запит: `recommendTiming({d: 500, g: 30, r: 30, o: 0}, 36)`

```json
{ "arr": 50, "g": 16, "r": 44, "o": 47 }
```

### applyTiming

Запит: `applyTiming(50)` для 4 світлофорів прикладу. Відповідь: масив `lights` оновлено, `sim(50).stops = 0`.

### validate

Запит при `speedKmh = 0`:

```json
[ "Скорость автомобиля: от 1 до 200 км/ч" ]
```

Запит при коректних даних: `[]`.

## Правила контракту

- Час у секундах, відстань у метрах, швидкість у км/год.
- Світлофори обробляються в порядку зростання відстані; ті, що далі за кінець маршруту, ігноруються.
- Сигнал зелений, якщо `((t − offset) mod cycle) < green`, де `cycle = green + red`.
- Зміна контракту, що ламає виклики, збільшує мажорну версію контракту.
