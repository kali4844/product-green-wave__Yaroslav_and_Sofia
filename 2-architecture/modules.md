# Модулі

| Модуль | Відповідальність | Операції | Залежить від |
| --- | --- | --- | --- |
| M1 Інтерфейс введення | поля параметрів, таблиця світлофорів, кнопки, перерахунок при зміні поля | `buildTable()`, `addLight()` і `removeLight()` (обробники кнопок), `applyTiming()` через кнопки, `render()` як точка входу | M2, M4, M5 |
| M2 Валідатор | перевірка введених даних за правилами VR-01…VR-12 | `validate()` | стан (поля форми, масив світлофорів) |
| M3 Симулятор проїзду | розрахунок часу, середньої швидкості, зупинок і очікування для заданої швидкості | `simulate(speedKmh)`, `signalAt(light, t)` (внутрішня) | стан |
| M4 Оптимізатор | пошук інтервалів і оптимальної швидкості, розрахунок оптимального зеленого й зсуву фази, застосування до таблиці | `scanSpeeds()`, `groupRanges(speeds)`, `recommendTiming(light, speedKmh)`, `applyTiming(speedKmh)` | M3 |
| M5 Візуалізація | таблиця результатів, повідомлення, показники, SVG-графік | `renderResults(result, scan)`, `renderChart(result)` | M3, M4 |

## Інтерфейси взаємодії

- M1 → M2: виклик `validate()` без параметрів, результат — список текстів помилок.
- M1/M5 → M3: `simulate(v)` повертає обʼєкт результату (див. [api.md](api.md)).
- M4 → M3: `scanSpeeds()` викликає `simulate(v)` для кожного кроку швидкості.
- M1 → M4: кнопки викликають `scanSpeeds()` і `applyTiming(v)`.
- M5 → M3, M4: бере результати розрахунку й рекомендації для відображення.
